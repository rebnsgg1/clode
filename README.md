# 🥗 Моє меню

Особиста книга рецептів: ПП та звичайні страви, рандом «Страва дня», меню на день з лімітом калорій,
тижневий планувальник, список покупок, режим готування й статистика. Працює офлайн і встановлюється на телефон як застосунок (PWA).

**Стек:** React 19 · Vite · TypeScript · Tailwind CSS v4 · компоненти shadcn/ui (Radix) · Framer Motion · Dexie (IndexedDB) · vite-plugin-pwa · dnd-kit

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (і в локальній мережі — адреса Network)
npm run build      # продакшн-збірка в dist/ (разом із service worker)
npm run preview    # перегляд продакшн-збірки
```

Інші команди: `npm run typecheck`, `npm run format`.

## Встановлення на телефон

Офлайн-режим і встановлення працюють через **HTTPS** (або `localhost`). Найпростіше —
задеплоїти папку `dist/` на будь-який статичний хостинг (Netlify, Vercel, GitHub Pages, Cloudflare Pages)
з переадресацією всіх шляхів на `index.html`.

- **iPhone (Safari):** відкрий сайт → кнопка «Поділитися» → «На початковий екран».
- **Android (Chrome):** відкрий сайт → меню ⋮ → «Встановити застосунок»
  (або кнопка в «Ще → Налаштування → Встановити на телефон»).

Після першого відкриття застосунок працює без інтернету. Дані зберігаються лише на пристрої (IndexedDB),
тож для перенесення використовуй **Налаштування → Експорт / Імпорт JSON**.

## Як додавати страви

- **В застосунку:** кнопка «+» (або «Нова страва» на десктопі). Фото стискається автоматично (до 1280 px, WebP/JPEG).
  Якщо в кроці є час («варити 10 хв») — кнопка таймера з'явиться сама.
- **Через код (стартовий набір):** додай об'єкт у `src/data/seed.ts` з унікальним `seedId`.
  КБЖВ — на 1 порцію, інгредієнти — на всі `servings`. Нові стартові страви підтягнуться в базу при наступному запуску
  (видалені користувачем — не повертаються; відновити можна в Налаштуваннях).

## Структура

```
src/
  data/seed.ts          стартові страви
  lib/                  db (Dexie), фільтри, рандом і генератор меню, список покупок, бекап, стиснення фото
  hooks/                тема, таймери, Wake Lock, встановлення PWA
  components/ui/        базові компоненти (shadcn-стиль)
  components/           картки, діаграма БЖВ, фільтри, таймери, навігація
  pages/                екрани застосунку
```
