# 🥗 Моє меню

Десктопна програма для Windows — особиста книга рецептів: ПП і звичайні страви, «Страва дня» зі слот-машиною,
меню на день з лімітом калорій, тижневий планувальник, список покупок, режим готування з таймерами та статистика.

Працює **повністю без інтернету**, усі дані зберігаються лише на твоєму комп'ютері.

## Встановлення

1. Відкрий сторінку [Releases](../../releases/latest) і завантаж `moie-menu_<версія>_x64-setup.exe`.
2. Запусти інсталятор. Якщо Windows покаже «Windows захистив ваш ПК» — натисни **Докладніше → Виконати однаково**
   (програма не підписана платним сертифікатом).
3. Інсталятор українською створить ярлик «Моє меню» на робочому столі й у меню Пуск і запропонує одразу запустити програму.

Права адміністратора не потрібні — програма ставиться для поточного користувача.
Потрібен Windows 10 або 11 (компонент WebView2 уже є в системі; якщо раптом немає — інсталятор докачає його).

## Дані та резервна копія

- Рецепти, план, історія й налаштування зберігаються локально в `%LOCALAPPDATA%\ua.moiemenu.desktop`.
- **Налаштування → Зберегти копію…** — зберігає всю базу в JSON-файл через стандартне вікно Windows.
- **Налаштування → Відновити з копії…** — відкриває JSON-файл; можна об'єднати з поточною базою або повністю замінити її.
- Під час видалення програми дані лишаються, якщо не поставити галочку «Видалити дані програми».

## Розробка

Потрібні [Node.js 22+](https://nodejs.org), [Rust](https://rustup.rs) і
[передумови Tauri для Windows](https://v2.tauri.app/start/prerequisites/) (Microsoft C++ Build Tools, WebView2).

```bash
npm install
npm run desktop   # запуск програми в режимі розробки (з гарячим перезавантаженням)
npm run bundle    # збірка інсталятора: src-tauri/target/release/bundle/nsis/
npm run dev       # лише інтерфейс у браузері (http://localhost:5173), без нативних функцій
npm run icons     # перегенерувати іконки з SVG-мастерів
```

**Стек:** Tauri 2 (Rust) · React 19 · Vite · TypeScript · Tailwind CSS v4 · компоненти shadcn/ui (Radix) ·
Framer Motion · Dexie (IndexedDB) · dnd-kit

### Реліз

Пуш тегу `v*` запускає GitHub Actions (`.github/workflows/release.yml`): збирається Windows-інсталятор
і публікується в GitHub Releases. Перед релізом підніми версію в `package.json` і `src-tauri/Cargo.toml`.

```bash
git tag v1.0.1 && git push origin v1.0.1
```

### Іконка

Мастери лежать у `assets/icon/`:

- `icon.svg` — основна іконка (48 px і більше);
- `icon-small.svg` — спрощений варіант для 16–32 px (без виделки й тіней, символ більший — щоб ярлик лишався чітким).

`npm run icons` генерує з них PNG для Tauri і багатошаровий `src-tauri/icons/icon.ico` (16, 24, 32, 48, 64, 128, 256 px) —
його використовують ярлик, панель задач, вікно програми та інсталятор.

### Як додавати страви

- **У програмі:** кнопка «Нова страва». Фото стискається автоматично (до 1280 px). Якщо в кроці є час
  («варити 10 хв») — кнопка таймера з'явиться сама.
- **Стартовий набір у коді:** додай об'єкт у `src/data/seed.ts` з унікальним `seedId`. КБЖВ — на 1 порцію,
  інгредієнти — на всі `servings`. Нові стартові страви підтягнуться під час наступного запуску
  (видалені користувачем — не повертаються; відновити можна в Налаштуваннях).

### Структура

```
src/                    інтерфейс (React)
  data/seed.ts          стартові страви
  lib/                  база (Dexie), фільтри, рандом і генератор меню, покупки, резервна копія
  pages/                екрани програми
src-tauri/              десктопна оболонка (Rust): вікно, системні діалоги файлів, інсталятор
  tauri.conf.json       вікно, інсталятор NSIS (українською)
  icons/                згенеровані іконки
assets/icon/            SVG-мастери іконки
scripts/                генерація іконок
```
